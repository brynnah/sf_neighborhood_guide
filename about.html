About Our Senior Project

This guide is a way to look around San Francisco neighborhood by neighborhood. Choose Map to click the illustrated map, or pick a name from the list, and a short profile opens beside it.

Each profile is its own page in the neighborhoods folder, so the writing for one area can be changed without touching the others. Photos can be added in that same page.

How the map works

The picture is a drawing of the city. A matching color layer underneath tells the page which neighborhood was clicked, and the sidebar loads that neighborhood's page.
